02  OBS

Add two sources

  1. A
    Window capture of the arena. Keep it focused while you play; it takes keyboard and gamepad input.
    http://127.0.0.1:8787/play/
  2. B
    Browser source above it: width 1920, height 1080, transparent, no custom CSS.
    http://127.0.0.1:8787/overlay/
  3. C
    Keep the forge console on a second monitor to approve ideas and run polls.
    http://127.0.0.1:8787/forge/

03  Real chat

Go live

  1. 1
    Sign in as the streamer.
    npm run auth -- broadcaster
  2. 2
    Sign in the chat bot (can be the same account).
    npm run auth -- bot
  3. 3
    Set TWITCH_ENABLED=true in .env.local, then start the server.
    npm run server

04  The show

What chat can do

Twitch chat
01!boss <idea>

Describe a boss. Codex builds it; the fairness gate checks it before it can reach you.

02!vote 1|2|3

Polls open between fights when 2+ bosses are verified. The winner fights next.

03!rematch

After you win, chat (or the boss's creator) sends it back to the forge as a harder MK II.

04!top · !record · !mybosses

Hall of Fame: creators earn points when their bosses fight, beat you, or get upgraded.

05!queue

Lists the verified bosses waiting for you.

06!approve · !reject · !skip · !startvote

Broadcaster and moderators only.
