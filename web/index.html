Chat designs the boss. Codex builds it. You survive it.

A viewer types one sentence in Twitch chat. A sandboxed Codex agent turns it into a playable bullet-hell boss, a bot proves the boss is fair, and it drops into the streamer's arena about a minute later, with the viewer's name on it.

01

From one chat message
to a boss fight.

  1. 01

    Chat

    A viewer sends !boss <idea> or redeems Channel Points. The bot replies with a short code; a mod approves with !approve.

  2. 02

    Codex

    A Codex SDK thread writes boss.json against a typed BossAPI in a locked workspace, runs the local checks, and fixes its own mistakes. Up to three attempts.

  3. 03◎

    The gate

    The server, not Codex, re-runs an unchangeable fairness gate on the real spec. Unfair bosses are rejected and their points refunded.

  4. 04⌁

    The arena

    The streamer fights it in a deterministic 60 Hz arena, captured in OBS, with a transparent overlay telling chat everything.

02

A reference bot with human-like reactions fights every boss on five fixed seeds. If a troll asks for a wall of bullets, the gate says no before it ever reaches the stream.

03

Chat keeps playing
after the boss dies.

  1. !rematch

    Rematch Patch

    Beat a boss and chat can send it back. Codex reads the fight stats and builds a harder MK II, which must pass the same gate.

  2. !vote 1·2·3

    Chat picks the fight

    Between fights a live poll lets chat choose which verified boss the streamer faces next, with bars on the overlay.

  3. !top

    Hall of Fame

    Every fight is recorded. Creators climb the board when their bosses beat the streamer.
